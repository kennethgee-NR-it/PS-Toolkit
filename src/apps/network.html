      Cable boxes and waste

      Pull the longest lines first from full boxes, then finish with short lines from what’s left. Set how many boxes go on the pulling rack: with more than one, each pull takes one cable from every box to lines from the same IT closet.

      Cable allowances

      Planned length = (routed length + closet allowance + drop at the device + service loops) × (1 + waste). TIA-568 limits the permanent link to 90 m (295 ft), leaving 10 m for patch cords in the 100 m channel.

      Documentation

      Hand these over with the job: the schedule and test report show every line’s label, port, length and result; the PNGs are the as-built drawing.

      Measured access points

      For each band, give the channel as channel@width (60@80 is channel 60 at 80 MHz) and list each BSSID with its network name, one per line. Leave the name off if none was recorded.
